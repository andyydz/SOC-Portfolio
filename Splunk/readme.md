#  Splunk

##  Overview

Splunk is a Security Information and Event Management (SIEM) platform used to collect, index, search, monitor, and analyze machine-generated data from endpoints, servers, network devices, applications, and cloud environments.

It enables Security Operations Center (SOC) analysts to detect threats, investigate incidents, perform threat hunting, and monitor an organization's security posture in real time.

#  Splunk in a SOC

Splunk acts as the central platform where logs from multiple sources are collected and analyzed.

Common log sources include:

- Windows Event Logs
- Linux Syslogs
- Firewall Logs
- VPN Logs
- DNS Logs
- Proxy Logs
- IDS/IPS Alerts
- Endpoint Security (EDR)
- Cloud Platforms (AWS, Azure, GCP)
- Active Directory
- Web Servers
- Authentication Logs

SOC analysts use Splunk to:

- Monitor security events
- Detect suspicious activity
- Investigate alerts
- Correlate events across systems
- Hunt for threats
- Support incident response
- Generate security reports

---

#  Typical SOC Workflow

1. Collect logs from multiple sources
2. Index and normalize data
3. Search using SPL
4. Correlate related events
5. Investigate suspicious activity
6. Validate findings
7. Escalate confirmed incidents
8. Document and close investigations
